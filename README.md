# 1BC

**STATUS: LAUNCH-SITE SCAFFOLD** — routes exist, product surface does not.

1BC is a launch site. The pages below resolve so portfolio and navigation
links work, but they are placeholder routes rather than shipped features.

That is stated here rather than implied by a set of pretty pages. A reader who
mistakes scaffolding for a product wastes their time; a reader who is told
immediately can decide whether to keep looking.

## Routes present

`/about`, `/contact`, `/dashboard`, `/governance`, `/page.tsx`, `/pricing`

## Status

| | |
| --- | --- |
| Product surface | placeholder routes only |
| Tests | none |
| CI | none |
| Real content | pending |

## Why it exists

Every venture in this portfolio has a public entry point. Where the product is
not ready, the entry point is labelled a scaffold rather than filled with
claims it cannot support. This repository will be replaced with real content
when there is something real to show.
